# World land illustration

`world-land.svg` derives from Natural Earth's public-domain 1:110m land polygons:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson

Downloaded 2026-10-06. Equirectangular projection over 180°W–180°E and
85°N–60°S. Antarctica is omitted. Coordinates are rounded to one SVG unit decimal.
The map is a geographic illustration, not a statement about boundaries or sovereignty.

License: https://www.naturalearthdata.com/about/terms-of-use/

Regional pins use approximate, explicitly supported regional centroids; they do not
identify physical data centers. Carbon observations come from the selected GreenOps
inventory. The asset does not contain carbon measurements or call an external map API.
