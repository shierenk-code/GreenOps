These diagrams describe the **target design**, not a claim that every component is implemented. In particular, proposed platform services, multiple LLM providers, hash-chained immutable storage and carbon-budget gates should not be inferred as working prototype capabilities. The current demonstration uses Gemini for optional model reasoning; its JSON ledger is not cryptographically immutable.

Read the [current implementation and agent design](overview.md) for implemented components, data sources, orchestration, human oversight, failure handling and execution boundaries. See also [submission status](../SUBMISSION.md).
