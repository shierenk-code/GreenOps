## Before sharing

- Test repository and folder access using the intended judge account/access route.
- Record the agent running, including evidence, a human decision, a supported sandbox change and its verification. A slide walkthrough alone is insufficient.
- Explain that plan approval is not deployment and that sandbox results are not production savings.
- Include agent sustainability figures with measurement methods and uncertainty; distinguish modelled estimates from measured results.
- Use public/open/synthetic data only. Hide account details, credentials and personal identifiers in recordings.
- Complete the team/timeline and pre-existing-component declarations before submission.
